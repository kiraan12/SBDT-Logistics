LR template image (optional)
============================
Place SBDT_page-0001.png, SBDT_page-0001.jpg, or lr_template.jpg/png here to
use it as the background for generated LR (Lorry Receipt) PDFs. The image is
never removed. If no image is found, the PDF is still generated with the same
layout and fields matching the SBDT template (3 copies: Consignor, Consignee,
Product of delivery).
